# Tic-Tac-Toe 🎮

A simple Tic-Tac-Toe game built using HTML, CSS, and JavaScript.

## 📌 About the Game

Tic-Tac-Toe is a two-player game played on a 3×3 grid. 
One player uses **X** and the other uses **O**.

Players take turns placing their symbol in an empty cell. 
The first player to get three of their symbols in a row wins.

The three symbols can be aligned:

- Horizontally
- Vertically
- Diagonally

If all 9 cells are filled and neither player gets three in a row, the game ends in a draw.

## 🎯 Features

- Two-player gameplay
- Win detection
- Draw detection
- Restart/New Game option
- Simple and interactive UI

## 🛠️ Technologies Used

- HTML
- CSS
- JavaScript

## 🚀 How to Play

1. Open the game.
2. Player X makes the first move.
3. Players take turns selecting empty cells.
4. Get three symbols in a row to win.
5. If the board is completely filled without a winner, the game is a draw.
